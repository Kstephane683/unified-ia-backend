**Diagnostic** : "Ton site s'affiche bien sur téléphone ?"
**Impact** : Google pénalise les sites non mobile-friendly (tu perds 60% de trafic)

**Diagnostic** : "Ton site commence par http:// ou https:// ?"
**Impact** : Google marque "Non sécurisé" → les visiteurs partent
